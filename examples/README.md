# 示例目录

这里展示真实的"输入 → Enough 输出"示例，覆盖典型复用决策和完整长任务，让你不安装也能直观看到 Enough 的效果。

- [reuse-decision-rss-guard.md](reuse-decision-rss-guard.md)：直接采用——发现现成项目完全满足需求，零行代码采用，而不是自建。
- [existing-codebase-feature.md](existing-codebase-feature.md)：现有代码库扩展——先做代码考古，再决定"只借鉴"并基于现状扩展。
- [new-project-build.md](new-project-build.md)：新项目自建——候选全部验证、缺口逐一确认后，才得出自建结论。
- [mind-journal-end-to-end.md](mind-journal-end-to-end.md)：完整长任务——约束变化后重评复用决策，按里程碑实施并逐项验收。
