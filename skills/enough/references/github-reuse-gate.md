# GitHub 复用门禁

## 目录

- 1. 定义搜索目标
- 2. 执行搜索
- 3. 评估证据
- 4. 作出并重新评估复用决策
- 5. 安全试运行直接采用的候选
- 6. 输出复用决策

对标准路径和高风险路径完整执行本门禁。目标不是为搜索而搜索，而是在自建前找到可以直接采用、扩展或借鉴的成熟实现。

## 1. 定义搜索目标

先写清：

- 一句话最终结果。
- 必需功能与非必需功能。
- 平台、部署方式、语言或框架限制。
- 隐私、安全、离线、许可证和维护约束。
- 哪些差异可以通过配置或小型扩展解决。

只询问阻止有效搜索的缺失信息。

## 2. 执行搜索

至少使用三类相互不同的查询：

1. 产品结果和使用场景。
2. 核心功能与平台或技术栈。
3. 中英文同义词、替代术语、Topics、Awesome 列表、上游与活跃 Fork。

优先使用 GitHub 仓库搜索；按需使用代码搜索确认关键能力是否真实存在。初筛约 10–30 个候选，保留 3–7 个，深入核验最匹配的 1–3 个。

连续两轮不同查询没有产生新的强候选时，可视为基本达到搜索饱和。记录搜索范围和限制，避免声称绝对穷尽。

除非用户明确要求更大范围，初筛达到约 30 个、深入候选达到 3 个或满足饱和条件后就停止扩张。高风险任务应加深对最终候选的安全与运行核验，而不是无限增加候选数量。

## 3. 评估证据

Star 与 Fork 只作辅助信号。优先评估：

- 必需功能和核心用户路径是否真实存在。
- 最近提交、版本发布和维护者响应。
- 自动测试、CI、安装文档和可复现演示。
- Issue 与 PR 是否显示严重未解决问题。
- 许可证是否允许预期使用和修改。
- 依赖、安全、数据去向和隐私风险。
- Windows、本地优先、离线或目标平台兼容性。
- 配置、迁移、升级和长期维护成本。

标记证据等级：

- **E3**：实际安装、启动或复现核心演示成功。
- **E2**：有测试、CI、发布和活跃维护等工程证据，但尚未本地运行。
- **E1**：只有 README、截图或作者声明。

所有复用决策和重评都只使用 E1、E2、E3；不要改写成 A/B/C、低/中/高或其他自定义等级。

不要把 E1 或 E2 描述为“功能已经本地验证”。

## 4. 作出复用决策

- **直接使用**：核心结果和必需功能已满足；平台、隐私、许可证与维护风险可接受；采用成本低于自建。
- **使用并扩展**：主体能力可用，缺口边界清楚且扩展成本合理。
- **只借鉴**：整体不适合，但架构、交互、数据模型、测试或部署方式有明确价值。
- **自建**：没有合适候选，或采用与迁移风险高于自建；说明原因和将借鉴的部分。

不使用虚假的精确百分比代替判断。围绕核心结果、不可妥协约束和总拥有成本给出推荐。

### 重新评估复用决策

当平台、部署方式、必需功能、数据边界、许可证或维护约束发生变化，并可能改变候选适用性时：

1. 标记发生变化的约束。
2. 只补查受影响的候选、证据与采用成本，不机械重复全部搜索。
3. 对比原结论与新结论，说明为什么保持或改变推荐。
4. 用新决策替代旧决策，再进入设计或实施。

例如，通用 PWA 可以在平台未定时被推荐为“使用并扩展”；用户随后确定必须是原生 Android、系统身份认证且不依赖 Web 存储时，应重新评估为“只借鉴”或“自建”，而不是继续沿用旧结论。

## 5. 安全试运行直接采用的候选

用户选择直接使用后：

1. 先核对许可证、安装方式、安全边界和数据去向。
2. 在隔离或可恢复环境中安装，不立即使用真实凭据或生产数据。
3. 运行启动冒烟测试和最小核心用户路径。
4. 逐项核对必需功能，记录配置、扩展和迁移缺口。
5. 实际成功后才将证据提升为 E3。
6. 失败时重新归类为使用并扩展、只借鉴或自建。

## 6. 输出复用决策

复用调研阶段唯一合法的回合结束状态是用户可见的“复用决策”。在暂停、请求确认或结束回合前，必须给出候选、证据等级、明确推荐、理由、搜索限制和下一步；不要用“准备收敛”“补一轮后输出”或类似内部进度句收尾。

使用简洁格式：

```markdown
## 复用决策

- 目标：
- 关键约束及变化（如有）：
- 搜索范围：
- 搜索限制：

| 候选 | 核心匹配 | 工程健康 | 许可证/安全 | 证据 | 主要缺口 |
| --- | --- | --- | --- | --- | --- |

- 推荐：直接使用 / 使用并扩展 / 只借鉴 / 自建
- 与上一版决策的变化（如有）：
- 理由：
- 下一步：
```

发现高度匹配项目时明确推荐直接使用，并暂停自建等待用户决定。GitHub 不可用或搜索明显不完整时，披露限制；未经用户确认，不继续自建。
